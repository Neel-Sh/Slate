# Slate

A calm, native iPhone client for Gmail: multiple accounts with a unified inbox, durable Undo Send, safe drafts, fast search, Later, and on-device summaries and suggested replies.

- Setup and running on your iPhone: [docs/SETUP.md](docs/SETUP.md)
- Design system and feasibility: [docs/DESIGN.md](docs/DESIGN.md)
- What works, what's tested, what's blocked: [docs/STATUS.md](docs/STATUS.md)
- New-mail push architecture: [docs/NOTIFICATIONS.md](docs/NOTIFICATIONS.md)

Swift + SwiftUI, iOS 26+, no third-party dependencies.
